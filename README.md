# ProClick Helper

Лёгкая замена Razer Synapse для мыши **Razer Pro Click Mini** в стиле [G-Helper](https://github.com/seerge/g-helper):
одно маленькое окно у панели задач, иконка в трее, без служб, учётной записи Razer и установки.

**Скачать:** последняя версия — в разделе [Releases](../../releases). Это один файл `ProClick-Helper.exe`, ставить ничего не нужно
(нужен .NET Framework 4.8, он уже есть в Windows 10 и 11).

## Возможности

- **Профили под программы.** «Обычный» профиль и профиль на каждую программу (Discord, игры, Photoshop…) —
  переключаются сами по активному окну. В профиле — назначения кнопок и своя чувствительность.
- **Чувствительность.** 4 общих уровня DPI по возрастанию; пятая ячейка — значение по умолчанию для текущей программы
  (последний выбранный уровень). Ползунок меняет значение выбранного уровня.
- **Назначение кнопок** с виртуальной клавиатурой, как в Steam: клавиши и сочетания, нампад, кнопки мыши,
  мультимедиа, переключение DPI, отключение кнопки.
- **Турбо** (аппаратный автоповтор) для кнопок мыши и клавиш, 5–30 нажатий в секунду.
- **Частота опроса** 125 / 500 / 1000 Гц (через приёмник), **время засыпания**, **заряд батареи**.
- **Тест мыши:** реальная частота опроса, разброс интервалов, провалы и рывки, счётчики нажатий —
  помогает понять, почему мышь дёргается по Bluetooth.
- **Оформление:** тёмная и светлая тема, акцентный цвет (или как в Windows).
- Мышь уснула — программа это видит, блокирует настройки и сама переподключается, когда мышь проснётся.

| | Приёмник 2,4 ГГц | Bluetooth |
|---|---|---|
| Чувствительность (уровни DPI) | да | да |
| Частота опроса | да | нет |
| Назначение кнопок, турбо | да | да |
| Время до засыпания, заряд | да | да |

Настройки записываются в память самой мыши и работают даже без запущенной программы.
Переназначить можно правую кнопку, нажатие колеса, две боковые и наклоны колеса. Левая не трогается намеренно —
чтобы нельзя было остаться без клика.

## Запуск

- Перед запуском закройте Razer Synapse.
- Галочка «Запускать вместе с Windows» внизу окна — программа будет стартовать в трей.
- Если что-то не применяется: «Экстра» → журнал обмена → «Скопировать».

## Сборка из исходников

Нужен .NET SDK 8 или новее:

```
dotnet build -c Release
```

Результат — `bin/Release/net48/ProClick-Helper.exe`.

## Протокол

- **Приёмник (USB HID):** 90-байтные feature-репорты Razer — по [OpenRazer](https://github.com/openrazer/openrazer)
  (Pro Click Mini Receiver, `1532:009A`). Назначение кнопок — по [razerqdhid](https://github.com/geezmolycos/razerqdhid).
- **Bluetooth (GATT):** служба `52401523-F97C-7F90-0E7F-6C6F4E36DB1C` — по [OpenSnek](https://github.com/gh123man/OpenSnek).
